# Contributing

Thank you for your interest in contributing.

We welcome:

- Bug reports
- Feature requests
- Documentation improvements
- Code contributions
- Tests and performance improvements

## Before you start

Please:

1. Search existing issues first
2. Open an issue for major changes before starting
3. Keep pull requests focused and small

## Code style

To make everyone's life simple, we use default prettier configs for all of our React / Frontend code and gofmt for Go files. We expect everyone to use these tools when contributing.
